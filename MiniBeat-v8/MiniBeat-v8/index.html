Advanced MIDI diagnostics

Each pad assignment stores a MIDI note and channel. If a piano key and pad send the exact same note on the same channel, the browser cannot tell them apart. Use the Drums first / Piano first selector above to decide which control wins an overlap. To play both independently at the same time, the Akai must send distinct MIDI messages.
