MiniBeat v8 — MIDI priority switch. Run py -m http.server 8000 in this folder, open http://localhost:8000, Connect MIDI, then Map Drum Pads if needed. Set Drums first (default) to play all mapped pads, or Piano first to restore overlapping piano notes. MIDI messages identical in note/channel cannot be independently distinguished; changing controller settings is needed for simultaneous full independence. Includes recording, audio import, WAV export.
